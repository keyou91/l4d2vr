# VR hands dependency setup

Run this once from a PowerShell prompt before building L4D2VR:

```powershell
powershell -ExecutionPolicy Bypass -File .\L4D2VR\setup_vr_hands_dependencies.ps1
```

The script downloads a fixed cgltf revision and ozz-animation 0.17.0 at commit `744eb9d99f606eda849acb0b1204f7a3dc20bca1`, then builds Win32/v142 Debug and Release static libraries with the DLL CRT (`/MD` or `/MDd`).

After installation it automatically removes the downloaded ozz-animation source tree, the CMake build directory, temporary files and duplicate per-configuration header trees. The retained dependency layout is intentionally compact:

```text
thirdparty\
  cgltf\
    cgltf.h
  ozz-animation-install\
    win32\
      LICENSE.md
      VERSION.txt
      include\
        ozz\...
      lib\
        Debug\
          ozz_animation.lib
          ozz_animation_offline.lib
          ozz_base.lib
        Release\
          ozz_animation.lib
          ozz_animation_offline.lib
          ozz_base.lib
```

The ozz runtime and offline libraries remain required because the plugin builds and evaluates an ozz runtime skeleton from the SteamVR hand hierarchy during initialization. World-model arm IK itself uses the same shared analytic two-bone solver as the first-person arms. `LICENSE.md` preserves the upstream MIT license and `VERSION.txt` prevents mixing headers and libraries from different revisions.

World-model arm lengths and shoulder positions come from the final Source pose for the current draw. Each controller drives the shared analytic two-bone solve with body-relative elbow continuity and a length-constrained wrist goal, while the two sides are solved independently from one immutable post-body/head pose. Source locomotion remains on the lower body, and the bounded firing rotation is still sampled back onto the weapon hand.

The setup script also migrates and cleans the older expanded layout. If the dependency folders were already generated by an earlier patch, run the script again once; it reuses the installed files and removes unnecessary directories without downloading them again.

At startup the plugin generates a copy of the SteamVR action manifest and its default binding JSON files, adding the left/right skeleton mappings without editing your original files.

The first implementation draws independent VR hands only when `mat_queue_mode == 0`. The queued renderer needs a DXVK-side safe submission point before raw D3D hand drawing can be enabled there.
